# حالة تنفيذ تطوير Moudie NetPlay

## ما تم تنفيذه

تمت إعادة صياغة الهوية البصرية للتطبيق لتستند إلى الصور المرجعية التي قدمها مالك المشروع: خلفية دوائر داكنة، بطاقات بنفسجية متوهجة، ألوان سماوية وبنفسجية، ورمز التطبيق المرفق نفسه. تم ربط الرمز بإعدادات أيقونة Expo، شاشة البدء، والواجهات الرئيسية.


أضيف دور `spectator` إلى مخطط قاعدة البيانات ومسارات الغرف وخادم الاتصال الفوري. يستطيع المشاهد البقاء داخل الغرفة والتواصل النصي والصوتي، لكنه لا يستطيع إرسال مدخلات اللعبة أو الدخول في تحقق جاهزية المحرك. كما تم توسيع الدردشة الصوتية الأصلية لتستخدم اتصالات WebRTC موجهة بين أعضاء الغرفة المتاحين، بدل الاعتماد على اتصال واحد فقط.

أضيفت شاشة لعب سوداء كاملة لشاشات اللعب المحلي، ولا تعرض سوى التحكم وإحصاءات FPS وPing ورقم اللاعب. لا تعرض الواجهة أرقامًا مصطنعة؛ تظهر القيمة `—` حتى يوفّر محرك المحاكي أو اتصال الغرفة قياسًا فعليًا. تمت إضافة لوحة تحكم قابلة للتحريك والتكبير والتصغير، مع حفظ مواضعها ومقياسها على الجهاز لكل محاكي. وتم توصيل هذه اللوحة أيضًا بوضع التركيز في Famicom.

## تشغيل ترحيل قاعدة البيانات


```bash
pnpm db:push
```

يتطلب الأمر متغير البيئة `DATABASE_URL` الصحيح.

## نقاط تحتاج إعدادًا أو تطويرًا إضافيًا

| العنصر | الوضع الحالي | المطلوب للإطلاق الكامل |
|---|---|---|
| اللعب المتزامن لأكثر من لاعبين اثنين | الغرفة تقبل حتى 10 أعضاء، مع مشاهدين وصوت ودردشة، لكن محرك NetPlay الموجود ما زال يزامن المضيف ولاعبًا واحدًا فقط في Famicom وPS1. | بناء بروتوكول إدخال ومزامنة مناسب لكل محرك متعدد اللاعبين، أو دمج خادم NetPlay متخصص لكل محاكي. |
| الصوت لعشرة أعضاء | توجد إشارات واتصالات WebRTC موجهة بين أعضاء الغرفة. | إعداد خادم TURN موثوق للإنتاج، واختبار الأداء على أجهزة وشبكات فعلية. الاتصال الشبكي المقيد قد يمنع الصوت المباشر دون TURN. |
| تسجيل Facebook أو البريد | المشروع يحتوي تدفق OAuth عام فقط. | إنشاء تطبيق Facebook وإضافة مفاتيح OAuth ومسارات العودة وسياسة الخصوصية، أو ربط مزود هوية يدعم البريد/كلمة المرور والتحقق من البريد. |
| FPS وPing | الواجهة جاهزة وتعرض قيمة غير مصطنعة عند عدم توفر القياس. | إضافة قياس FPS من كل محرك محاكي وقياس زمن الاستجابة عبر Socket/WebRTC ثم تمريرهما للشاشة. |

## التحقق المنفذ

تم تنفيذ فحص TypeScript واختبارات Vitest. النتيجة: 27 اختبارًا ناجحًا، واختباران متخطيان بسبب احتياجهما إلى إعدادات خارجية. فحص Expo لا يحتوي أخطاء، لكنه ما زال يعطي تحذيرين قديمين في شاشة Famicom وPS1 لا يتعلقان بالتطوير الجديد.
