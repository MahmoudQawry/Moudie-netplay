# تحقق بناء Moudie NetPlay

## المعاينة

تم فتح معاينة الويب للردهة بنجاح. تعرض الواجهة الهوية الجديدة، واللعب المحلي، والغرف حتى عشرة أعضاء، والانضمام برمز، وبطاقات NES وPS1 وPSP وSega وArcade. معاينة الويب تعرض الواجهة فقط؛ تشغيل النوى الأصلية واختيار ملف اللعبة يتطلب APK Android.

## الفحوص البرمجية

| الفحص | النتيجة |
|---|---|
| TypeScript | ناجح عبر `pnpm check` |
| اختبارات Vitest | 27 اختبارًا ناجحًا، واختباران متخطيان لإعدادات خارجية |
| تجميع وحدة المحاكي Kotlin | ناجح |
| بناء APK Debug | ناجح |
| توقيع APK | صالح بتوقيع APK v2 |

## محتوى APK

يتضمن APK arm64 نوى FCEUmm وPCSX-ReARMed وGenesis Plus GX وPPSSPP وMAME Arcade. حجمه كبير لأنه يضم نواة MAME كاملة؛ تُراجع استراتيجية تنزيل النوى عند الطلب قبل إصدار الإنتاج لتقليل حجم التحميل الأولي.

## ما لا تثبته هذه البيئة

لم يتم تشغيل ألعاب ROM/BIOS فعلية داخل الجهاز الافتراضي لأن التطبيق لا يتضمن ROM أو BIOS ولا يتوفر جهاز Android متصل. كما أن LiveKit وCoturn جاهزان في الكود وملفات النشر، لكنهما لا يصبحان خدمة عامة حتى يُنقلا إلى خادم دائم بعنوان عام ومفاتيح سرية.
