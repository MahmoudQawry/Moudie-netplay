# Moudie NetPlay — سجل تحقق الإصدار 1.4.0

**تاريخ التحقق:** 18 أغسطس 2026  
**حزمة التسليم:** `MoudieNetPlay-v1.4.0-arm64-release.apk` لنظام Android `arm64-v8a`  
**معرّف التطبيق:** `com.app.moudienetplay`  
**رقم البناء:** `23`

## نطاق الإصدار

يغطي هذا الإصدار التحكم المنفصل لكل زر، الواجهة الإنجليزية الكاملة، اختيار اتجاه اللعب ونسبة الشاشة عند بدء الغرف، دعم ملفات PS1 بصيغة ISO، غرف PSP، تنظيم الصفحة الرئيسية إلى Create Room وJoin Room وLocal Play فقط، وإتاحة أزرار الميكروفون والدردشة في أوضاع اللعب المدعومة.

## نتيجة التحقق

أُجريت **عشر دورات تحقق متتابعة** على الشفرة وحزمة Android النهائية. نجحت جميع الدورات المطلوبة. تحذيرات Gradle العامة المتعلقة بإصدارات مستقبلية وتحذيرات إهمال في قالب React Native لا تمنع البناء، ولا تظهر أخطاء TypeScript أو ESLint في المشروع.

| الدورة | نطاق التحقق | النتيجة |
|---:|---|---|
| 1 | `pnpm test` | نجح: 27 اختباراً ناجحاً. |
| 2 | `pnpm check` | نجح: TypeScript بلا أخطاء. |
| 3 | `pnpm lint` | نجح: ESLint بلا أخطاء أو تحذيرات للمشروع. |
| 4 | مسح النصوص الظاهرة | نجح: مصدر الواجهات والمشغلات باللغة الإنجليزية فقط. |
| 5 | عقد التحكم المستقل | نجح: تحريك وتكبير وتصغير وحفظ الزر المحدد موجودة في Universal وPS1 وFamicom. |
| 6 | `expo export --platform android` | نجح: حزمة Metro مستقلة بحجم 4.9 MB. |
| 7 | `:moudie-emulator:compileReleaseKotlin` | نجح: تجميع Kotlin لوحدة المحاكي الأصلية. |
| 8 | عقد PSP وISO والاتجاه | نجح: مسار PSP ودعم ISO وتمرير خيارات الاتجاه ونسبة الشاشة موجودة. |
| 9 | `:app:assembleRelease` | نجح: بناء APK الإنتاجي للإصدار 1.4.0. |
| 10 | فحص APK النهائي | نجح: سلامة ZIP، المحتوى، معمارية arm64، والبصمة والتوقيع. |
