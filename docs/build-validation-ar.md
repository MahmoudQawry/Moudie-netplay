# Moudie NetPlay — سجل تحقق الإصدار 1.3.0

**تاريخ التحقق:** 18 أغسطس 2026

**حزمة التسليم:** `app-release.apk` لنظام Android `arm64-v8a`

**الهدف:** التحقق من تعديلات التحكم القابل للتحجيم، دعم PlayStation Portable، قبول PS1 ISO، الوضعين العمودي والأفقي، مسارات الغرف، واللغة الإنجليزية.

## نتيجة التحقق

أُجريت عشر دورات تحقق متتابعة على شفرة التطبيق وحزمة Android النهائية. نجحت الاختبارات الوظيفية والبنائية المطلوبة. سجّل فحص ESLint تحذيرين معروفين فقط عن اعتماديات `useEffect` في شاشتي Famicom وPS1، من دون أي أخطاء تمنع البناء أو التشغيل.

| الدورة | نطاق التحقق | النتيجة |
|---:|---|---|
| 1 | `pnpm test` | نجح: 13 ملف اختبار، 27 اختباراً ناجحاً، وملفان متخطيان بشكل متوقع. |
| 2 | `pnpm check` | نجح: TypeScript بلا أخطاء. |
| 3 | `pnpm lint` | نجح بلا أخطاء؛ تحذيران غير حاجبين فقط. |
| 4 | `:moudie-emulator:compileReleaseKotlin` | نجح: تحققت Kotlin من دعم ISO، التدوير، وأدوات التحكم الأصلية. |
| 5 | `expo export --platform android` | نجح: أُنشئت حزمة Metro مستقلة بحجم 5.04 MB. |
| 6 | عقد دعم PS1 ISO | نجح: الامتداد موجود في الكتالوج والتحقق الأصلي ومسار غرفة PS1. |
| 7 | عقد الاتجاه | نجح: أنشطة المحاكيات تدعم `fullSensor` وتخطيطات منفصلة للوضعين. |
| 8 | عقد التحكم | نجح: تحريك، تكبير باللمس المتعدد، وأزرار `SIZE − / +` موجودة في الأسطح المطلوبة. |
| 9 | عقد التنقل | نجح: الصفحة الرئيسية تتضمن Create Room وJoin Room وLocal Play فقط، ومسار PSP موجود داخل الغرف. |
| 10 | `:app:assembleRelease` | نجح: APK إصدار arm64 مع JavaScript مضمّن بالكامل. |

> لا تتضمن الحزمة ألعاباً أو ملفات BIOS. يستخدم اللاعب ملفاته القانونية الخاصة. يحتاج اختبار الأداء وملفات ROM الفعلية إلى هاتف Android فعلي، وهو اختبار لا يمكن محاكاته داخل بيئة البناء دون جهاز متصل.

## ملاحظات التثبيت

الحزمة تستهدف هواتف Android الحديثة بمعمارية **arm64-v8a**. الإصدار هو APK حقيقي موقّع بحساب التطوير ويحتوي JavaScript داخله؛ لذلك لا يعتمد على خادم Metro أو رابط معاينة عند التشغيل.
