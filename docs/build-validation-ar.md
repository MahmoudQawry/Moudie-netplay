# Moudie NetPlay — سجل تحقق الإصدار 1.4.12

**تاريخ التحقق:** 19 أغسطس 2026

**حزمة التسليم:** `MoudieNetPlay-v1.4.12-animated-intro-startup-fix-arm64-release.apk` لنظام Android `arm64-v8a`

**معرّف التطبيق:** `com.app.moudienetplay`

**رقم البناء:** `35`

## نطاق الإصلاح

يعالج الإصدار `1.4.12` الشاشة السوداء التي تظهر بعد شعار Android. كان النشاط الأصلي يخفي شاشة البداية بمهلة ثابتة قبل أن يرسم React Native أول إطار، فتظهر مساحة سوداء إذا تأخر تركيب الواجهة أو حدث خطأ فيها. أزيل هذا الإخفاء القسري؛ يحتفظ Android بشعار البداية حتى أول إطار React Native. كما أضيفت حدود استرداد مرئية تحيط بشجرة الواجهة: إذا وقع استثناء أثناء الرسم، يعرض التطبيق شاشة **MOUDIE IS READY** وزر **TRY AGAIN** بدلاً من مساحة سوداء غير قابلة للتفاعل.

بعد أول إطار، يظهر افتتاح Moudie متحرك مدته 2.5 ثانية. يبدأ بظرف تقني مغلق، يفتح ليكشف بطاقات PS1 وPSP وNES وSega وArcade، ثم يظهر ختم M وأخيراً توقيع **Moudie**. تتوفر عبارة **SKIP INTRO** دائماً لتجاوز الحركة فوراً؛ لذلك لا يمنع الافتتاح الوصول إلى الردهة.
