# مبادئ غرفة Classic Era

هذه الملاحظات تحدد نموذج الغرفة للتنفيذ في Classic Era by Moudie، ولا تمثل نسخاً لواجهة أو محتوى لعبة أخرى.

| مبدأ | قرار التطبيق |
| --- | --- |
| **الغرفة خادمية السلطة** | الخادم هو مصدر الحقيقة لدور العضو والسعة والجاهزية وحالة الجلسة؛ لا يقرر العميل وحده البدء أو المقعد المتاح. |
| **الفصل بين الدورين** | يخصص حد مستقل قدره 8 مقاعد للاعبين و2 للمشاهدين. اللاعبون فقط يحجزون مقاعد الإدخال ويدخلون في شرط الجاهزية؛ المشاهدون يشاهدون ويتحدثون ولا يرسلون إدخال لعب. |
| **حالات واضحة** | `WAITING_FOR_PLAYERS` ثم `WAITING_FOR_READY` ثم `IN_PROGRESS`، مع بث لقطة الحالة كاملة عند الانضمام أو الاسترداد. |
| **غرف عامة وخاصة** | الغرفة العامة قابلة للاكتشاف من قائمة الردهة؛ الخاصة تستخدم رمز دعوة قصيراً. تعرض القائمة النظام وحالة الجلسة وعدد المقاعد المتاحة فقط، لا ROM أو BIOS أو بيانات خاصة. |
| **مرحلة ما قبل اللعب** | قبل البدء، يختار اللاعب ملف اللعبة المحلي وBIOS حيث يلزم، ثم تؤكد البصمة وإصدار المحرك المطابقان وتظهر حالة الجاهزية. |
| **البدء** | لا يسمح للمضيف بالبدء إلا بعد تحقق الجاهزية وشروط مطابقة الملف؛ تحفظ إعدادات التحكم والشاشة قبل فتح المشغّل كي تبقى شاشة اللعب خالية من عناصر التحرير. |

تشير وثائق Nakama إلى الاحتفاظ بحالة اللاعب والجاهزية وحالة المباراة في خادم موثوق، وإلى بث حالة الجاهزية للمنضمين لاحقاً، والتمييز بين الغرف العامة والخاصة وقائمة الغرف.[1] كما تبيّن وثائق Unity أن منطقة اللوبي مرحلة مستقلة تحفظ بيانات اللاعب وحالة الاستعداد قبل الانتقال إلى اللعب.[2]
